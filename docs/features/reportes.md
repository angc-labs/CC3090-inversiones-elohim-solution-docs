# Reportes y Análisis

## ¿Qué es?
El módulo de reportes te proporciona visibilidad completa sobre el desempeño de tu tienda con gráficos, métricas y tendencias en tiempo real.

## Para qué sirve
- Visualizar ventas diarias, mensuales y anuales
- Identificar productos más y menos vendidos
- Analizar rentabilidad real por producto/sucursal
- Detectar patrones de compra de clientes
- Comparar desempeño entre períodos (mes anterior, año anterior)
- Exportar datos para análisis externo

## Casos de uso
1. **Toma de decisiones**: ¿Qué productos invertir más stock?
2. **Análisis de tendencias**: ¿Cuándo es temporada alta? ¿Qué épocas son lentas?
3. **Evaluación de campañas**: ¿El constructor visual mejoró las ventas?
4. **Auditoría financiera**: Reconciliar ventas con ingresos reales
5. **Presentación a stakeholders**: Generar reportes para socios o inversionistas

## Características clave
- **Dashboards personalizables**: Elige qué métricas ver primero
- **Filtros avanzados**: Filtra por sucursal, producto, rango de fechas, método de pago
- **Comparativas**: Compara períodos lado a lado
- **Gráficos interactivos**: Hover sobre datos para detalles
- **Exportación en múltiples formatos**: CSV, PDF, Excel

## Métricas disponibles
- **Ingresos totales**: Dinero entrante real
- **Cantidad de transacciones**: Número de órdenes
- **Ticket promedio**: Monto promedio por venta
- **Productos vendidos**: Unidades vs ingresos
- **Tasa de conversión**: Visitantes que compran
- **Margen de ganancia**: Ingresos vs costo de productos

## Integración con otras funciones
- Obtiene datos de **Configuración de Pagos** (ingresos por método)
- Analiza **Inventario** (rotación de stock)
- Se combina con **Constructor Visual** para medir impacto de cambios de diseño
- Muestra desempeño por **Sucursal**

## ¿Cómo acceder?
Ve a **Reportes** en la barra lateral de tu panel administrativo.

Todos tus datos se actualizan automáticamente cada vez que hay una venta.
